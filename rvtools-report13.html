    Security Awareness
    เทียบเวอร์ชัน/build ของ ESXi และ vCenter ที่ตรวจพบกับฐานข้อมูล VMware Security Advisory (VMSA) พร้อมระดับความรุนแรงและวิธีแก้ไข

    ช่องโหว่ที่อาจกระทบกับ Environment นี้

    ตรวจสอบ CVE/VMSA ล่าสุดจาก NVD

    กำลังตรวจสอบข้อมูลล่าสุด...
    ⚠ ฐานข้อมูล VMSA หลักในเครื่องมือนี้เป็นรายการที่คัดเลือกเฉพาะ Critical/Important ที่สำคัญ (ปรับปรุงล่าสุด ก.ย. 2569) ไม่ใช่รายการที่ครบถ้วน 100% การจับคู่ระดับ host ใช้เวอร์ชันหลัก (major.minor) เสมอ และจะเทียบ เลข build จริง เพิ่มเติมเฉพาะ VMSA ที่เครื่องมือมีเลข build อ้างอิงยืนยันแล้วเท่านั้น (จะระบุไว้ในแต่ละรายการ) — ส่วนที่เหลือต้องเทียบ build เองกับ Response Matrix ส่วน "ตรวจสอบ CVE/VMSA ล่าสุดจาก NVD" ด้านบนจะดึงข้อมูลจาก National Vulnerability Database แบบสดตอนนำเข้าไฟล์ เพื่อช่วยแจ้งเตือน CVE ใหม่ที่อาจยังไม่ถูกเพิ่มในฐานข้อมูลหลักของเครื่องมือนี้ (อาจใช้ไม่ได้หากเบราว์เซอร์/เครือข่ายบล็อกการเชื่อมต่อออกนอก) โปรดตรวจสอบ Response Matrix ของแต่ละ VMSA บน Broadcom Support Portal เพื่อความถูกต้องก่อนตัดสินใจ
